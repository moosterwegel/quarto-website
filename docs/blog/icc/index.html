As Geoffrey Rose powerfully illustrated over 40 years ago, we need variability in our studies to study health. However, not all variability is productive to the conduct of our studies. For example, in environmental epidemiology you have technical variation from biological assays, and exposures that not only vary over person and place but also over time. Such variation over time can introduce classical measurement error. This can complicate our studies that are often limited to a single measurement per subject. In this post, I will go over the intraclass correlation to quantify the useful between-subject variability in your population.

Ideally, to quantify the amount of measurement error we compare our measurement to a ‘true’ measurement or a gold standard. This would be a validity study. However, for many exposures in environmental epidemiology this is infeasible. [example]. Often, the best we can do then is assume that the ‘true’ measurement is the average over time, obtain multiple, temporally separated measurements and compare those. In epidemiology, we would call this a reliability (of the mean) study.

If you can’t know the truth, the next best thing is knowing if you can tell Person A apart from Person B.

get_icc_anova <- function(m) {
  stats <- summary(m)[[1]]
  
  MS_between <- stats["subjectid", "Mean Sq"] 
  MS_within  <- stats["Residuals", "Mean Sq"]
  
  var_within <- MS_within
  
  # in anova, MS_between includes both the true between-subject variance AND within-subject noise.
  # expected MS_between = var_within + (k * var_between), where k is measurements per subject.
  # to isolate pure var_between, we subtract MS_within and divide by k (here, k = 2)
  var_between <- (MS_between - MS_within) / 2
  
  var_between / (var_between + var_within)
}

get_icc_lmer <- function(m) {
  vc <- lme4::VarCorr(m)
  var_between <- as.numeric(vc[[1]])
  var_residual <- attr(vc, "sc")^2
  var_between / (var_between + var_residual)

Besides taking the proportion of variance that is between subjects, we can also take the ratio of within- to between-subject variance. Gelman offers an interesting information theory perspective on this ratio. Namely, it quantifies the information content of the population distribution in terms of actual samples. Specifically, the value represents the number of observations you would need from a single subject (i.e., class) to match the information already provided by the population prior – the global mean.1

For example, if within-subject variance is two times the between-subject variance (within-subject variance is 2, between-subject variance is 1, for an ICC of 0.33), there is technically more information about a subject’s true mean in the global mean than in that subject’s own data if a subject has fewer than 2 observations. In other words, if you had to guess a subject’s true mean, you would do better to use the population mean than the single observation you had on that subject. Conversely, with an ICC of 0.2 you would need 4 observations on a subject to match the information from the global mean!

Interestingly, some earlier writings on exposure variability in environmental and occupational epidemiology calculated this ratio instead of the ICC. Looking more into it, it seems that this is more standard in biostatistics.

So, when \(n=1\), the attenuation factor is exactly the ICC: \(\beta^* = \beta \times \text{ICC}\). The ICC gives you the reliability of a single measurement.

Crossed, nested, random slope, and left-censored models

The random intercept models we usually use to calculate the ICC are super flexible, and allow you to easily add crossed effects (for example if you also have different raters or different batches (also a different rater in some way)), or specify a three-level model when some of the variation between subjects is simply variation between different countries.

For biological data, we can also easily model the left-censoring mechanism for the nondetects using brms and STAN such that we do not need to impute and can directly obtain an estimate of the variances. In this Bayesian framework we can also get the uncertainty of the ICC estimate for free.

fit_and_calculate_icc <- function(y, other_data_formula, rhs_formula, 
                                  below_lod_indicator, 
                                  batch_var = NULL, return_model = FALSE, 
                                  write_result_to_disk_path = NULL,
                                  compound_name = "", ...) {
  require('brms')
  cmdstanr::set_cmdstan_path('C:/Users/Public/Documents/.cmdstan/cmdstan-2.35.0')
  
  # double colons don't place nice with filenames
  compound_name <- stringr::str_replace(compound_name, ':', 'double-colon')
  
  left_cens <- label_left_cens(y, below_lod_indicator)
  is_left_censored <- any(as.logical(left_cens))
  
  if(is_left_censored) {
    lod <- suppressWarnings(get_lod_per_batch(y, other_data_formula[[batch_var]], below_lod_indicator))
    y <- ifelse(left_cens, lod, y)
  }
  
  df <- dplyr::bind_cols(other_data_formula, "y" = log(y), "left_cens" = left_cens * -1, 
                         "lod" = ifelse(is_left_censored, log(lod), 'no_lod'))
  
  m <- brms::brm(formula = brms::brmsformula(as.formula(glue::glue("y | cens(left_cens) ~ {rhs_formula}"))), 
                 data = df, 
                 backend = 'cmdstanr', ...)
  
  p_samples <- brms::as_draws_df(m)
  
  icc_draws <- purrr::pmap_df(
    .l = list(
      sigma_1 = p_samples[['sigma']],
      sigma_2 = p_samples[['sd_id__Intercept']]),
    .f = \(sigma_1,sigma_2) compile_icc_stats(sigma_1, sigma_2))
  
  summary_stats <- posterior::summarise_draws(icc_draws, "mean","median","sd","mad",
                                              ~quantile(.x, probs = c(0.025, 0.975)),
                                              "rhat", "ess_bulk", "ess_tail")
  
  r <- list("summary_stats" = summary_stats, "summary_model" = broom.mixed::tidy(m))
  
  if(!is.null(write_result_to_disk_path)) {
    readr::write_rds(r, here::here(write_result_to_disk_path, glue::glue("{compound_name}.rds")))
  }
  
  if(return_model) {
    return(list("model" = m, "summary_stats" = summary_stats))
  }
  
  return(r)
}

compile_icc_stats <- function(sigma_1, sigma_2) {
  return(list("sigma_1" = sigma_1,
              "sigma_2" = sigma_2,
              "icc" = sigma_2^2/(sigma_1^2 + sigma_2^2)))
}

Bland-Altman plot

ICCs are mainly useful for designing and interpreting epidemiological studies. They are less useful for judging whether your measurement is useful for clinical interpretation as you can also obtain a high ICC value when the within subject variability is very large if your between-subject variability is even larger (measurement error of this magnitude unacceptable is clinically unacceptable). A Bland-Altman plot is a better device to test this.

  1. This calculation is derived from equating the precision (inverse variance) of the population prior with that of the sample mean. From an information theory perspective, the standard deviation quantifies uncertainty – meaning a narrower distribution (higher precision) contains more information. By setting the standard deviation of the between-subject distribution (\(\sigma_{\text{between}}\)) equal to the standard error of the within-subject sample mean (\(\sigma_{\text{within}}/\sqrt{n}\)), we identify the point where the prior and the data provide equivalent information. Solving for \(n\) yields the variance ratio \(n = \sigma^2_{\text{within}} / \sigma^2_{\text{between}}\). This value represents the “equivalent sample size” of the prior. Practically, this defines the tipping point for partial pooling: below this threshold, the multilevel model shrinks estimates toward the global mean; above it, the specific subject’s data dominates.↩︎
